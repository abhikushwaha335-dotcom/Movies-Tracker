# 🎬 MovieFinder

MovieFinder is a modern and responsive movie & anime tracker website that helps users discover trending movies and TV shows with direct legal streaming search links for platforms like Netflix, Crunchyroll, and Prime Video.

Built using **HTML**, **Tailwind CSS**, and **JavaScript**, this project uses the **TMDB API** to fetch real-time movie and anime data.

---

## ✨ Features

- 🔥 Trending Movies & TV Shows
- 🔍 Real-time Search Functionality
- 🎞️ Movie Posters & Descriptions
- 📅 Release Date Display
- 📺 Legal Streaming Search Links
- ⚡ Fast & Responsive UI
- 🎨 Modern Dark Theme Design
- 📱 Mobile Friendly Layout

---

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (Vanilla JS)
- TMDB API
